# Required facts — review before re-grading (rubric v2.1)

Each golden answer now has a `required` field: ONLY what the question asks for, decided from the
question's wording. Everything else in `answer` is optional context: leaving it out costs nothing,
but stating it WRONGLY is still D.

Rules used: fact → the figure asked · "How did X change" → both figures + direction (size of change
and the reason are optional) · "Which is higher" → the winner + both figures · narrative → the points
that directly answer what was asked · unanswerable → refusal.

Edit `required` in golden.jsonl if you disagree with any line, then save.
